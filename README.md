##  Project Overview
A data-driven trading assistant built to monitor financial markets in real-time. Utilizing **n8n** workflows, this agent fetches live market data, performs technical sentiment analysis using AI, and sends instant trade alerts to the user.

##  Key Features
- **Live Data Fetching:** Integrates with financial APIs for real-time price updates.
- **Market Sentiment Analysis:** Scans news and social trends to gauge market volatility.
- **Instant Alerts:** Sends signals via Telegram or Discord for quick decision-making.

##  Tech Stack
- **Automation Tool:** n8n.io
- **Data Source:** Crypto/Stock APIs (e.g., CoinGecko, Yahoo Finance)
- **AI Integration:** OpenAI / Custom Logic Nodes

## 🚧 Project Status: **Work In Progress** 
Focusing on optimizing signal accuracy and backtesting the AI's predictive logic.
